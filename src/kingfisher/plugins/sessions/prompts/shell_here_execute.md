- The shell exports the session root, the directory the file tools call `/`, as `$KINGFISHER_SESSION_ROOT`. Put it in front of a file-tool path, slash included -- `/{{inputs}}/data.csv` is `"$KINGFISHER_SESSION_ROOT/{{inputs}}/data.csv"` -- in the command and in any script it runs, where it is read as `os.environ["KINGFISHER_SESSION_ROOT"]` rather than pasted; use the optional timeout to override the default.
- The shell writes under `/{{outputs}}` and `/{{scratchpad}}` (which is `$TMPDIR`) and nowhere else: `/{{inputs}}` is refused, and so is the session's top, where the shell starts -- a bare `> out.csv` is refused where `"$KINGFISHER_SESSION_ROOT/{{outputs}}/out.csv"` is not.
