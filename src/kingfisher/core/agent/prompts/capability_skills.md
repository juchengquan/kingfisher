## Skills

`/skills` holds reusable procedures, one directory per skill. Read a skill's
`SKILL.md` when its subject matches the task at hand rather than working from memory,
and prefer an existing procedure over inventing a new one.

The catalogue is yours to read and not to write: it is shared by every session, so a
skill edited here is read by every later run. Say what a procedure should say differently
in your answer, rather than editing it.
